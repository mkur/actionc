# Preserved MyDOS Source

`MYDOS453.ARC` is the unchanged MyDOS 4.53/3 distribution archive obtained
from:

```text
https://www.mathyvannisselroy.nl/mydos453.arc
```

Identity:

```text
size:    87522 bytes
SHA-256: 52853bdf6fa03c73cf1292c9ec6ca355f8109056d71a7531b05b51a4fdb75e87
```

It is an ARC archive using dynamic LZW compression. An ARC-compatible extractor
such as `nomarch` can unpack it. The archive contains:

- `MDOS.M65`, `MDOS1.M65`, `MDOS2.M65`, and `MDOS3.M65`;
- `MDUP.M65`, `MDUP1.M65`, `MDUP2.M65`, and `MDUP3.M65`;
- `MD453_3.DSK`, the Disk Communicator release image;
- `READ.ME`, `CONTENTS.`, and the `RB6C2.AR0` RAM-disk helper.

The `.M65` files are machine-readable MAC/65 saved-source files. See
`../MYDOS-NOTICE.md` for copyright terms, attribution, binary identities, and
the relationship between this source release and actionc's configured ATR.
